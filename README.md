# StarGPT Android

StarGPT es la evolución de MultiAI. Este repositorio alojará el proyecto Android, el icono de StarGPT y la compilación de prueba mediante GitHub Actions.

## Estado del repositorio

El proyecto fuente **todavía debe subirse**. El ZIP `StarGPT_Android_v0.5.11-alpha-source.zip` contiene una carpeta de proyecto Android; se puede subir al directorio raíz y extraer automáticamente desde el workflow, o subir directamente los archivos del proyecto. No se deben subir claves API ni contraseñas.

Cuando el proyecto esté aquí, abre la pestaña **Actions → Build StarGPT APK** para compilar y descargar el artefacto `StarGPT-debug-apk`.

**Aviso:** el inicio de sesión compartido con Google requiere configurar OAuth y un servidor HTTPS; compilar el APK no configura estos servicios automáticamente.
